# 诸神愚戏 · 信仰试炼

一款基于小说《诸神愚戏》前 248 章设定改编的纯前端网页游戏。你将扮演主角**程实**，以【欺诈】信徒的身份进入信仰世界，在诸神试炼中编织谎言、结交队友、提升登神与觐神点数。

## 特性

- **谎言编织系统**：程实专属玩法，基于“从不骗人，从不相信任何人”的角色内核
- **天梯排行榜**：欺诈与记忆的天梯，实时试炼排名（第 6-50 名每局随机轮换）
- **神明觐见系统**：与各神明的交互，包含特色对话与试炼
- **信仰世界大厅**：NPC 动态社区，可与排名玩家互动
- **成就系统**：分类展示与搜索
- **试炼库**：每局抽取 9-12 个试炼，加权去重算法

## 技术栈

纯 HTML / CSS / JavaScript（原生，零依赖，零构建），所有逻辑在浏览器本地运行。

## 本地运行

任选其一：

1. 直接双击打开 `index.html`
2. 或启动本地服务器：`python -m http.server 8080`，访问 http://localhost:8080/

## 自动部署

仓库配置了 GitHub Actions（`.github/workflows/deploy.yml`）：每次推送到 `main` 分支自动执行 JS 语法检查（`node --check`）与必需文件校验，通过后自动部署到 GitHub Pages。
